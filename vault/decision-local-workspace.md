# Quyết định — Bộ não AI Local Workspace

## Tóm tắt
> Chọn hướng **Local Workspace (Obsidian + obsidian-skills)** làm bộ não riêng cho AI, do Claude Code vận hành. Không dùng giải pháp cloud-only hay Agent Memory Layer.

## Chi tiết
- Người dùng không rành kỹ thuật → cần giải pháp **sở hữu & inspectable** (mở Obsidian là thấy).
- Ưu tiên local, tránh vendor khoá chặt dữ liệu.
- NotebookLM vẫn dùng làm công cụ nghiên cứu riêng, **không** cấp nguồn cho vault.
- Claude Code là nơi vận hành (Collect → Organize → Evolve → Use → Govern).

## Lý do
- Bảo mật: dữ liệu nằm trên máy, không phụ thuộc cloud.
- Kiểm soát: người dùng tự mở/sửa/xóa note bằng Obsidian.
- Mở rộng: thêm sub-brain mới chỉ cần tạo thư mục + namespace tag.
