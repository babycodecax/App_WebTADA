Công cụ rà soát BCTC làm được gì?

Bác tải file Excel (.xlsx, .xls) hoặc Word (.docx) chứa báo cáo tài chính lên, công cụ tự kiểm tra các sai sót số liệu thường gặp rồi trả kết quả kèm nút xuất PDF và Word. Xem thêm cách tính các sắc thuế tại công cụ tính thuế.

File của em có bị lưu lại không?

Không. File chỉ dùng để rà soát ngay lúc đó, không lưu trữ. Mỗi file tối đa 10MB, bác tải được nhiều file một lúc.

Dùng công cụ có mất phí không?

Miễn phí toàn bộ. Bác chỉ cần đăng nhập Google một lần là dùng được ngay, không giới hạn số lần rà soát.

Rà soát xong, bác đọc thêm gì?

Ghé kho bài viết để hiểu các lỗi BCTC hay gặp và cách sửa, hoặc tra thư viện văn bản khi cần đối chiếu quy định mới nhất.
